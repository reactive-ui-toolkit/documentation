Reactive UI Toolkit

React-style UI for game engines.

One component model, every engine. Function components, hooks, and a fiber reconciler that diffs each render and patches only what changed — implemented natively for each engine, and authored in a JSX-like markup language that compiles to that engine's own code.

Godot

GDScript .guitkx Godot 4.x

Plain GDScript — no C#, no autoload. Components patch a real Control tree, and .guitkx compiles to a sibling .gd with hot reload that preserves hook state.
